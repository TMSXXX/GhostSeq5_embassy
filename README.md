# GhostSeq5
一个基于 STM32F401 和 **Embassy** 的简易合成器
## 主要功能
- 一个旋律轨+四个鼓轨的 BPM 可调 32步 音序器
- 12 半音全音阶，可进行半音调整和八度调整
- 双振荡器 FM 合成器，且可分别调整 ADSR，音色丰富
- 四个独立的鼓轨道，其中一个可自定义录音采样，采样支持约 2 秒
- 自定义录音采样可以进行倒放和变调变速
- 有 Haas, Saturator, Bitcrusher 等后处理效果器
- 有 口吃、TapeStop 两个简易的效果器

## 操作逻辑
面板共有 16 个按键，从左到右、从上到下依次命名为 1——12 号键，以及音色键、节奏键、录音键、播放键
其中，音色键和节奏键可以进入音色调整面板和节奏面板，当在其中一个面板再次点击对应按键时，回到默认面板，即旋律面板
电位器始终决定音量大小
### 旋律面板
1——12 号键分别对应一个八度内 12 个半音，旋转编码器可以调整八度范围，按住编码器调整可以调整半音范围
### 音色面板
1、2 号键分别决定载波和调制波的波形，有方波、锯齿波、正弦波、三角波
3 号键切换音量和调制强度的 ADSR 调制模式
在音色面板，主要调制都由编码器进行。
4：FM 的 Index
5——8：ADSR
9：Saturator
10：Bitcrusher
11：Haas（开关）
### 节奏面板
1、2、3 号分别为 Kick, Snare, Hat，4 号为自定义采样，通过按12号键可以进行采样的录制
9 号为自定义采样的倒放键，10 号为口吃，11号为 TapeStop
在该界面旋转编码器可以调整自定义采样的速率/音调，按下编码器旋转可以调整 BPM
